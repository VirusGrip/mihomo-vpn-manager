# Как помочь проекту

1. Создайте Issue с описанием проблемы и версией Debian/Ubuntu, Mihomo и Python.
2. Удалите из логов ссылки подписки, токены, пароли, публичные IP и другие секреты.
3. Создайте ветку, внесите минимальные изменения и добавьте тесты.
4. Запустите `python3 -m unittest discover -s tests -v` и `bash -n install.sh`.
5. Откройте Pull Request с описанием изменений и способа проверки.

При добавлении новых протоколов нужны примеры **с вымышленными секретами** и тесты разбора ссылок.
