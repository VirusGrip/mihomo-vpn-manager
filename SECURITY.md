# Безопасность

## Сообщение об уязвимостях

Не публикуйте секреты и эксплуатационные детали уязвимостей в открытых Issues. Свяжитесь с владельцем репозитория приватно (например, через GitHub Security Advisories → Report a vulnerability, если функция включена).

## Секреты

Ссылки подписки, пароли узлов и ключи считаются секретами. Никогда не добавляйте в репозиторий `/etc/mihomo-manager/state.json`, `/etc/mihomo/config.yaml` или реальные URL подписок. При утечке перевыпустите токен.

## Границы доверия

Установщик предназначен для чистой тестовой машины, запускается с root-доступом и скачивает Mihomo из GitHub Releases. Контроль подписи бинарника пока не реализован. Не запускайте непроверенный код в производственной инфраструктуре.
